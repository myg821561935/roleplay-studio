# 角色剧场 v1.1.0-rc.2 阶段目标

基线：`5f010d3`，上个候选版 v1.1.0-rc.1。此阶段以三类已知缺陷及真实多轮状态验证为边界，完成后推送 GitHub。

## 必须验收

1. 正常验看、包装、取回以及否定“加条件”的说明不被误拦截；同句中“无需押金，但必须签字”等真正新门槛仍受保护。
2. 对已经收存且承诺随时可取回的物品，NPC 的自主离场、后台日程或未经授权转交不能让约定失效。归还后应能正常离场，不把已完成事项变成永久留场锁。已有存档中确实离场者不可瞬移，需如实处理。
3. 两名以上 NPC 的明确交接、前者/后者、明确持有人和所有者指代能够同步；多人均符合代词时不猜测人物或物品，澄清后可继续。所有权不得随持有人改变。
4. 冻结最终代码后，在现有卡和预设的隔离副本上运行两组新生成多轮会话：约定与离场、多人交接与歧义。不得以全局“NPC 必须留场”代替离场修复；每轮实际保存并重新读取，核对正文、承诺、人物位置与物品状态。保留失败、重写和调用次数，原文重放仅作回归补充。
5. 全量测试、干净工作区发布检查、GitHub CI 通过。私有卡、预设、对话和密钥不进入仓库。

## 范围与限制

保留原卡文风，最多一次自动修正，仍无法可靠判断则不提交。此次不承诺通用契约推理、任意远距离指代、多层容器或所有模型与角色卡均通过。不改历史会话。模型扩写、语言误判和样本覆盖边界如实列入发布记录；新增目标进入下一阶段。
