# 本地社区资源组合验证

入口：

```sh
node scripts/validate-local-roleplay-resources.mjs <inventory.json> <output-dir>
```

清单为 JSON 数组，每项提供 `file`（本地绝对路径）、`name` 和 `sha256`。使用真实文件的清单与结果应放在被忽略的 `work/` 等本地目录，不将社区原文加入公开测试夹具。

验证器会检查文件哈希，通过正式导入预览与素材库服务执行导入、重复导入和读回，并将每张不同角色卡与所有预设、独立世界书、正则包组合。每组经过组合审核、剧本创建、会话保存、读回和提示词装配，检查原卡名称、配置持久化、预设保留、近期历史以及小预算的明确拒绝行为。

角色卡与内置世界书成套选入；额外世界书测试会加入本轮组合。脚本规则在临时验证副本中逐项拒绝，仅测试受支持的声明式路径，不把脚本禁用后的成功称作原资源完整运行。

每张角色卡选择一份轮换预设，完成两次发送与一次继续。模型接口使用固定、无网络的替身，实际组装的请求经过 OpenAI 请求序列化，生成事件交给前端 SSE 解析器核对正文、权威回合和完成事件；随后核对存档。这是跨层数据与事件验证，不是浏览器视觉验收或真实模型写作质量评测。

`macroSemantics` 另行检查嵌套赋值、注释副作用和变量内模板展开。它使用独立的行为期望，不能因常规测试通过而跳过。原卡字段覆盖与未展开模板记录为诊断项，需要区别作者原文、自动补全字段和待支持模板，不以字符串包含检查代替语义证明。

宏解析按成对大括号和源码顺序执行，注释不执行内部宏，条件只执行选中的分支。变量值和命名模板中的宏继续展开；循环引用保留未能解析的引用，不重复执行同一递归链上的写入。展开深度超过 24、宏求值超过 10,000 次、单段输入或输出超过 1,000,000 字符时，以 `MACRO_EXPANSION_LIMIT` 明确失败。提示词不再沿用显示模板的 120,000 字符前缀截断。上述边界有独立测试，不代表支持所有社区自定义宏或脚本。

退出码：

- `0`：已执行检查通过，清单中的文件均可识别。
- `1`：导入、组合、对话断言或宏语义检查失败。
- `2`：没有上述检查失败，但有不支持的导入格式。

结果为输出目录的 `results.json`。临时素材库、剧本、会话与假模型配置存放在独立临时目录，结束后清理，不修改用户当前素材库、模型配置或会话。原有社区分类签发表与此验证矩阵独立，不能机械将扫描器结果写成新的验收预期。
