# Roleplay Studio v1.1.0-rc.1

叙事状态一致性阶段候选版。它整理上个本地里程碑之后累计的提示词、兼容性、对话与世界模拟改动，建立可以继续迭代的 GitHub 基线。

## 主要变化

- **原卡和预设执行**：保留社区预设变量链，修复当前回合宏引用、世界书插入位置、预算与来源优先级；提供原样优先和增强模式。
- **故事连续性**：主角身份、离场事实、已完成动作、世界时钟和回合快照统一；增加历史修复与事实来源检查。
- **承诺与物品**：区分待协商、已承诺、已执行；物品所有者、持有人、位置、容器分别记录，移动不自动改变所有权，寄存不等于赠送。
- **复杂指代**：根据现有物品批次、空间位置、持有人、前者/后者和近邻先行词解析；等价批次不会重复扣减，歧义不强行选择。
- **条件保护**：已有约定在生成前明确注入。发现可识别的新门槛、伪造已同意条件或无法落实的收存或归还证据时，先在副本上实际应用动作核对最终状态，最多重写一次；仍违规则不提交。普通发送、流式发送和续写使用同一校验，修正调用计入用量。
- **导入与运行**：整合资源评估、脚本治理、轻/重前端兼容、Provider 路由、后台维护及可选 Pi 运行时。Pi 保持可选，默认不因本版本自动切换。
- **版本管理**：包版本与服务版本统一为 `1.1.0-rc.1`；自带适配器声明支持当前版本；新增固定依赖安装、CI 与阶段范围文档。

## 升级说明

数据 schema 仍为 v3。旧库存按需初始化为物品记录，旧对话不自动改写。升级前建议创建本地备份；备份可能包含凭据，不可上传 GitHub。

第三方插件与内容包明确声明的引擎范围继续生效。原包如果要求 `<1.0.0`，需要作者或使用者确认兼容后更新其声明；本版本不会绕过限制。没有统一支持的动态人设脚本，不因本版本号升级而被宣称已兼容。

涉及已有约定的流式回合会等校验通过后再展示正文，因此这类回合的首字延迟可能增加。自动修正最多增加一次模型调用；失败会报告本轮未保存。

## 验收记录

- 最终冻结叙事代码后的全新会话：12 轮全部实际保存并重新读取；20 次 API 请求，包含后台维护与 2 轮自动修正，无拦截后重试。采用现有角色卡和预设，native 运行时，DeepSeek 官方接口 `deepseek-flash` 别名；不凭别名推断上游具体版本。
- 检查承诺的三个阶段、寄存与赠送、所有权、持有人、位置、歧义不移动、最终库存及时间同步；动作重放与实际保存结果一致。原始卡、预设、世界书和原存档哈希未变。
- 这是 NPC 留场、赠品不消耗或转交的连续柜台交接受控场景。先前 15 个诊断会话记录保留，不能将最后一次通过解释为首次成功率或开放剧情全部通过。
- 全量自动测试 1,496/1,496；兼容测试 103/103；独立目录干净安装、Pi 实际加载与发布检查通过。
- 隔离存档备份恢复通过：与原始会话 JSON 内容一致，与初始化后备份基线字节一致。首次演练发现的是初始化补换行导致的字节差异，无内容丢失。
- 两轮自动修正不能都计为成功拦截真实违规：第 6 轮的正常验看被保守规则误判。正文仍扩写了旁人与线索，出现过代词性别漂移；这些不属于本次状态断言通过的范围。

## 已知边界

- 指代解析与新增条件检测仍有语言和场景覆盖范围，可能漏判或误拦截（本次已观察到正常验看误拦截）；它们不是通用语义证明。多层容器、复杂多人转交、远距离代称与完整契约履行需后续扩充。
- 已执行记录事项的具体动作，不代表将来的所有义务已经兑现。复杂义务应分开建项。
- 开放剧情仍可能自行安排保管人离场，再以钥匙不在等理由延迟取回。该实际失败已保留；本次最终状态验收明确限定为 NPC 留场的连续交接，不能据此声称任意开放剧情中的违约与拖延均被解决。
- 模型可能自行增加气氛、旁人或线索；本版本重点防止这些内容改写有效承诺和物品，不承诺消除所有无依据剧情扩展。
- 一个角色卡与预设的多轮通过不能证明所有卡、模型或长对话都通过。真实样例、API 请求响应与对话保留在本机，仓库只发布框架与合成测试。
- 本机旧社区样本审计仍有 5 项预期差异（原阻止运行、现安全降级）及 5 个待补样本。安全降级未执行第三方代码，不等于完整兼容；完整本地社区矩阵未通过。
- 正文仍可能重复气氛和道具描写，执行边界有时表达过于直白；本次不宣称活人感已追平其他模型。
- 本版本是候选版，不是完成全面安全审计或所有第三方兼容验证的稳定版。许可证选择和进一步公开发布治理仍是后续事项。

阶段目标、纳入范围及下一阶段边界见 [冻结范围](release-v1.1.0-rc.1-scope.md)。
