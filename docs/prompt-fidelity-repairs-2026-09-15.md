# 本轮提示词修复与对照边界

## 状态与节奏

- `format_message_variable::路径` 作为只读状态宏展开，保留数值 0、布尔 false 和结构化对象；缺失状态输出 JSON null，不虚构初始化值。支持显式 messageVariables 与会话轻前端变量。
- faithful 记忆层不再二次按字符／token 切断已经结构化压缩过的世界状态 JSON。最终总预算仍由提示词预算检查处理。
- 原卡明确要求“节奏缓慢”或“不急于推进剧情”时，对已识别的两条强制悬念／新变量句子做局部适配。强调完成当前互动也算推进，允许自然收束。原始卡和预设文件不改写，预览变化记录中可看到“原卡节奏适配”。`options.resolvePacingConflicts: false` 可禁用适配。不符合这组明确句式的规则不自动重写。

## 人物资料

核实发现修仙卡的基础信息、性格调色盘等静态条目仍然存在，使用原作者的关键词触发机制。上次固定初始提示词的对照未在后续轮次重新激活世界书，因此不能据此判断完整资料始终不可用。

新的对照为两组指定同一开场人物，并通过 `assembleTurn` 每轮重新组装提示词：只传入各自的剧情历史，不把上轮整份提示词当作剧情历史反复累加。没有把全部角色资料强制设为常驻，也没有声称已支持被隔离的 EJS 多阶段脚本。

## 评阅修正

上次阅读稿遗漏多个 content 段中的后续正文，导致“答非所问”的错误判断，已撤回并补全旧阅读稿。新的阅读稿保留所有正文与标签外叙述，仅移除指定的分析／传音／选项／状态协议。原始响应不改写。

## 实验限制

两次独立重复，每次两组各三轮，共十二次真实调用。使用当前卡／预设配置与开场前记忆快照，每轮重新组装。没有写回原会话，也不执行正式会话的状态提交和后台维护。新增的静态资料与节奏适配对两组完全相同。

这是同一日常场景的有限重复，不能替代多角色卡、长剧情、工具检索和多位读者的评估。观察到某组更好，也不能仅凭这种小样本推断运行框架造成了文风优势。
