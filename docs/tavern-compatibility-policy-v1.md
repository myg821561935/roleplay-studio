# 酒馆资源兼容政策 v1

> 本文保留为历史政策。新增兼容能力与验收以 [`tavern-compatibility-contract-v2.md`](tavern-compatibility-contract-v2.md) 和 v2 黄金资源矩阵为准。2026-08 起，本地开发环境采用“探索先行、审计收敛”的运行策略：放宽的是进入隔离运行时的审批门槛，不是第三方代码的权限边界。

## 定位

本项目兼容酒馆资源格式和常见交互语义，但不直接复刻酒馆的第三方扩展运行环境。确需执行的第三方 JavaScript 必须进入本项目的审核、隔离与审计链。

以下边界不可放宽：

1. 格式兼容不等于运行时兼容。
2. 安全降级必须显式提示，不能静默丢失语义。
3. 没有真实样例与自动化测试数据，不宣称覆盖率。
4. 本地探索模式下，第三方 JavaScript 可先在受控、无网络的沙箱中运行并完整记录；严格模式仍要求人工审核和内容哈希绑定。明确拒绝或撤销始终立即阻断当前内容哈希。
5. 人工授权只对当前内容哈希有效；内容变化、授权撤销或策略版本变化后自动失效，并重新进入观察或严格审批流程。
6. 发布与日常使用时，脚本只能在无父页面权限、默认禁止联网的隔离沙箱中运行；无法隔离的 DOM、iframe、网络请求与不可控递归仍不执行。
7. 仅本地开发可显式启用“开发兼容探针”：它只向无同源权限的子 iframe 开放外部资源、网络、表单、嵌套页面与 Worker，并完整审计启动、加载与错误；不开放主页面 DOM、存档、Cookie、Provider 密钥、本机进程或 MCP。此模式用于测量真实兼容缺口，完成后必须切回本地探索或严格审批。
8. 独立重前端属于完整第三方应用，不与角色卡、世界书或轻前端脚本共享授权；包版本、运行实例、模型预算和存档快照分别治理。

## 三态验收

### 完整映射

固定样例中的主要声明式行为与原资源语义一致，自动化快照或行为断言通过。完整映射只对已登记样例和已测能力负责，不代表同类市场资源全部兼容。

### 安全降级

静态角色、世界书、Prompt、图片和说明内容可以保留；导入报告必须列出差异、风险、内容哈希与处理建议。本地探索模式可直接进入隔离运行并产生审计，严格模式才要求逐项授权。

### 阻断运行

资源脚本内容哈希不匹配、被用户明确拒绝、请求沙箱外 DOM/iframe/网络能力、依赖隐式宿主对象或存在不可控递归时，可以保存原件供审阅，但不得执行对应脚本。报告必须给出具体阻断项。

## 基准库

脱敏基准位于 `tests/fixtures/compatibility/`，目前覆盖：

- 纯文本角色卡。
- 安全显示正则卡。
- Quick Reply 与白名单状态命令卡。
- MVU 状态卡。
- 可静态转换的重前端信息面板卡。
- 必须审核或阻断的动态脚本卡。

样例只保留实测字段结构和最小虚构文本，不包含社区原卡正文、图片、作者信息或可执行代码正文。新增兼容声明前，必须先补样例和验收断言。

## 受控语义

- 世界书二级关键词支持四种 `selectiveLogic` 语义。
- 显示正则替换支持 `{{char}}`、`{{user}}`。
- `/setvar`、`/incvar` 转换为 MVU 补丁，不直接解释执行脚本。
- `onImport`、`onUser`、`onAssistant` 只执行受预算约束的声明式补丁。
- 状态更新使用白名单路径和 `set`、`increment`、`delete`，任一步失败整次回滚。
- 可执行 Regex replacement 必须具备脚本 ID 和当前 SHA-256 内容哈希；本地探索模式允许其进入无网络、无宿主权限的沙箱，严格模式还要求审核决定和策略版本匹配。开发兼容探针仅供本地调试，可开放子 iframe 的浏览器侧外部能力，但不会变成酒馆宿主或获得应用密钥。
- 每次授权、拒绝、撤销、脚本启动和运行错误都写入本地会话审计记录；审计记录不得作为跨内容版本的授权凭据。

## 独立重前端

从酒馆角色卡继续发展出的独立网页或 WebView 应用，使用 `lra.heavy-frontend-pack/v1` 接入，不转换为轻前端面板，也不把它自己的 Prompt 再送入本项目的 Agent 装配链。

- 原始网页目录只保存在 `private-content/heavy-frontends/`，不得提交仓库。
- 每次导入按文件哈希生成不可变版本；新版本默认进入本地观察运行，人工批准或明确拒绝只绑定当前包哈希。
- 应用运行在独立 `*.heavy.localhost` 来源中，iframe 不授予弹窗、下载、表单、设备、顶层导航或父页面 DOM 权限。
- CSP 默认只允许同源脚本、样式、媒体和连接；外部字体、图片、代理、WebSocket、Worker 和 iframe 默认阻断。
- 模型调用使用随机短期能力路径（并设置 HttpOnly Cookie 作为同站优化）进入本地网关，服务端强制 Provider、模型、并发、调用次数、输入体量和输出 Token 上限。
- 审计只记录包、版本、模型、字符量、时长、状态和错误码，不记录 Prompt 或剧情正文。
- 应用原有浏览器存档保留在其独立来源；若应用公开兼容的 `storageService.buildSavePayload`，可额外保存不含向量的托管快照。

完整边界、接口和已知限制见 [`heavy-frontend-runtime-v1.md`](heavy-frontend-runtime-v1.md)。

预算常量由 `server/compat/lifecyclePolicy.js` 统一定义，执行器不得绕过。

## 变更要求

每次兼容能力扩展必须同时包含：

1. 脱敏结构样例。
2. 预期三态结论。
3. 行为或快照测试。
4. 导入报告中的用户可见差异。
5. 对显式拒绝、授权撤销、越权脚本，以及严格模式下未审核或哈希变化脚本不执行的回归断言。
6. 审核记录和执行审计的持久化断言。

技术框架仓库不得提交第三方角色卡、世界书、Prompt、立绘或个人故事存档。
