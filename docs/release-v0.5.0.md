# Roleplay Studio v0.5.0

发布日期：2026-07-27

## 定位

`v0.5.0` 是 Roleplay Studio（角色剧场）的稳定自用版，也是酒馆资源兼容路线的首个冻结基线。它兼容酒馆资源格式和常见交互语义，但不复刻酒馆的第三方代码运行环境。

本版冻结后不再按函数存在与否宣称兼容，只按脱敏基准和自动化验收给出结论。

## 冻结能力

- 导入评定固定输出“完整映射 / 安全降级 / 阻断运行”，并展示差异或阻断原因。
- 六类脱敏结构样例覆盖纯文本、正则、Quick Reply、MVU、静态重前端和动态脚本阻断。
- 世界书 `selectiveLogic` 四种二级关键词语义已进入检索测试。
- 显示正则替换支持 `{{char}}`、`{{user}}`，只作用于渲染副本。
- `/setvar`、`/incvar` 转换为白名单 MVU 补丁；未知命令继续禁用。
- 声明式 `onImport`、`onUser`、`onAssistant` 使用统一预算，失败时整事件回滚。
- 角色状态、任务、关系和静态说明可转换为原生侧栏；动态 JavaScript、DOM、iframe 和网络请求继续阻断。
- 非流式与流式会话都保存生命周期报告和补丁，便于复现。

## 验收口径

- 完整映射只表示登记样例的主要行为已通过自动化断言。
- 安全降级必须保留静态内容、禁用不安全部分并列出差异。
- 阻断资源可以保存审阅，但不能进入运行流程。
- 当前不提供也不计划提供未知第三方代码运行环境。
